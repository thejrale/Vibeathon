# Vibeathon: EIRA Cytology Capture (Building a ODK)

Proyecto generado en Nerdearla durante el vibeathon.

Offline capture of the EIRA cytology form on Android tablets (ODK Collect), synced to one ODK Central server, exported as CSV.

- `xlsform/`: questionnaire source and XLSForm
- `deploy/`: ODK Central deployment (existing server via SSH, or DigitalOcean/AWS/GCP via API token)
- `docs/`: [MVP scope and phases](docs/MVP_SCOPE.md), [decisions](docs/DECISIONS.md)
- `tests/`: form test cases
